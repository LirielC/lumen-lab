# Ícones do LumenLab

`tabler/` contém os SVGs Outline do [Tabler Icons](https://github.com/tabler/tabler-icons), obtidos em 10/09/2026, sob licença MIT. A licença original acompanha os arquivos em `tabler/LICENSE`. Apenas a cor `currentColor` foi substituída por `#69B7FF`, o azul do tema escuro, para renderização consistente no Qt.

`lumenlab.svg` é a marca própria do aplicativo: uma abertura iluminada com frentes de onda. É um símbolo esquemático, não um resultado de simulação.

Todos os arquivos são locais e incluídos no pacote do PyInstaller.
